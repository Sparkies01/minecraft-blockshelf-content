# BlockShelf Content

Content repository for the BlockShelf Minecraft Bedrock catalog.

- Display images: stored under `images/`
- Minecraft downloads: stored as GitHub Release assets
- Catalog metadata is served by the encrypted BlockShelf API and is not stored
  in this public repository.
